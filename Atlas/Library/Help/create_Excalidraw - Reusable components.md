> [!text] Thesis — paraphrase
> Zsolt's [02:07 chapter](https://www.youtube.com/watch?v=P_Q6avJGoWI&t=127s) introduces the stencil library. Reusable components provide a personal visual vocabulary.

## Application

If needed, enter edit mode with **Cmd+E**.
Open Library with **Cmd+Shift+L**.
Personal Library stores your own saved objects.
Use **Novak–Cañas** for concepts, labelled relationships, a proposition, and a focus question.
Use **ArchiMate** for architecture types and relationships.
[[Excalidraw - ArchiMate]] explains their meaning.
Each set has a separate heading. Search filters items across all groups.

| Library | Use |
| --- | --- |
| UML Activity | Actions, decisions, forks, and swimlanes |
| Interface Wireframes | Buttons, forms, screens, and layout sheets |
| User Journeys | Stages, roles, emotions, and journey templates |
| Gantt | A manual schedule with task bars |

Open Library (**Cmd+Shift+L**), search for an item, then click its preview (**mouse only**).
The new packs use editable native shapes and Excalifont.
Use **Cmd+Shift+G** to ungroup a component sheet when needed.
UML shapes do not validate the model. Gantt dates and bars require manual edits.

Drag a component into **Your space** (**mouse only**).
Double-click its label to edit (**mouse only**).
Press **Escape** to finish editing.
Component drag-and-drop still needs a reliable desktop check.

## Novak–Cañas Concept Mapping

The set follows the [Novak–Cañas method](https://cmap.ihmc.us/docs/conceptmap.php).
Start with a focus question. Give concepts short names.
Label each connection so both concepts and the linking phrase form a meaningful statement.
The Proposition stencil reads: **Concept maps → represent → knowledge**.
Use **Cmd+Shift+G** to ungroup it before moving the concepts separately.
Place general concepts above specific concepts where helpful. Cycles and multiple roots are valid.
Add labelled cross-links between branches when their relationship matters.
Use your own linking phrases. Review meaning before agents create structured records.

## Limit

Treat inserted components as independent copies.
Do not assume library changes update existing drawings.
Excalifont, rounded boxes, and arrowheads are presentation choices, not required notation.
[Zsolt's companion article](https://www.zsolt.blog/2021/07/sketchnoting-for-pkm.html) supports a personal visual vocabulary.
