> [!text] Thesis — paraphrase
> Zsolt's [09:18 chapter](https://www.youtube.com/watch?v=7DDY8rRDzdU&t=558s) covers the Slideshow side panel. The original drawing can provide an ordered review route.

## Application

Create a short route through the schematic's main argument.
Start playback with **Cmd+Shift+Enter**.
Open the controls with **Cmd+click** on the Slideshow toolbar icon.
Use the panel to order or exclude frames (**mouse only**).
End playback with **Backspace** before editing or opening a source link.

Playback passed a local check. Native fullscreen restoration and Backspace still need a fresh desktop check.
Attach review questions as slide notes.
Retain one visual source instead of maintaining a separate slide document.

## Limit

The [current v4 script](https://github.com/zsviczian/obsidian-excalidraw-plugin/blob/master/ea-scripts/Slideshow.md) supports notes and multiple decks.
Older instructions about alphabetical ordering can be outdated.
Marker frames can define slides, but do not include their visible contents in agent packets.
