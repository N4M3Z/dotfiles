> [!text] Thesis — paraphrase
> Zsolt's [05:55 chapter](https://www.youtube.com/watch?v=5G9QF-u9w0Q&t=355s) shows PDF++ integration. Selected PDF text becomes a linked MindMap Builder node.

## Application

Proposed use, untested locally: place a short source excerpt beside the claim it supports.
Select PDF text (**mouse only**).
Copy its passage reference with **Cmd+Shift+K** while the PDF view has focus.
Retain the PDF link when an agent proposes a structured note.
Keep source evidence distinct from interpretation.
Test one document before making this a routine capture method.

## Limit

This workflow requires MindMap Builder, PDF++, and selectable PDF text.
It does not perform OCR on scanned pages.
The [PDF++ integration references](https://ryotaushio.github.io/obsidian-pdf-plus/community-resources.html) support this connection.
Installed plugin compatibility still needs a local test.
